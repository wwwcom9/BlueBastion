# 蓝垒防线 BlueBastion

第二十一届"我的互联网+"绘蓝杯科技竞赛 · 软件赛道 · 游戏开发方向
参赛题目：2D 塔防游戏

## 项目简介

一款 2D 网格塔防游戏。玩家扮演"城市电网指挥官"，在被数据洪流侵蚀的赛博都市中，
沿数据总线部署防御模块，抵御入侵体，守护核心服务器。

- **防御模块**：脉冲炮（单体高频）、电磁风暴（范围溅射）、冻结力场（减速 + 易伤），各 3 级升级
- **敌人**：蠕虫（基础）、疾行体（高速）、护盾体（护盾）、修复体（治疗周围敌人）
- **关卡**：3 张地图（城区总线 / 地下管廊 / 核心机房），每关 6 波
- **创新点**：属性共振（异属性交替命中累积共振层）、主动过载（短时攻速翻倍，代价过热）
- **表现**：URP 2D 渲染 + 灯光 + Bloom，几何图形程序化美术，零外部素材依赖
